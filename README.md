## 💫 About Me:
👋 Hi, I’m Pratik Kumar Mishra

Software Engineer | Distributed Systems | Search & Data Platforms

I’m a Full Stack Software Developer at Automote, working on large-scale data systems that handle hundreds of millions of records.
My day-to-day work revolves around scaling backend systems, search infrastructure (Elasticsearch), sharded MongoDB, and high-throughput pipelines.

I enjoy solving hard engineering problems — the kind that involve performance bottlenecks, data consistency, infra trade-offs, and system reliability.
Beyond work, I love deep solo coding sessions, gym workouts, and spending time in nature to reset my mind.
